Quarto teaching template

One reference for the book, the slides and the features that connect them

Create a course, write teaching materials and share improvements across courses using the same self-contained Quarto template.

This manual documents the template derived from Outils informatique II and used by Analyse géospatiale. It covers the HTML book, the customised clean-revealjs slide theme, the local teaching features and the Git workflow connecting them. Start with the first guide for a new course; use the other three as references while authoring.

Getting started

Create a course, separate local and reusable YAML, prepare dependencies, name files, preview and build.

Book guide

Use answer/question profiles, numbered callouts, exercises, notebooks, citations and light/dark styling.

Slide guide

Compose layouts and fragments, animate figures, style text, configure profile icons and extract standalone slides.

Maintenance

Move reusable commits between repositories, transfer complete dependencies and diagnose rendering problems.

What belongs to the template

The template has two main content folders, course/ and slides/. Shared functionality is kept in _template.yml, local styles, filters, scripts and extension folders. Each course keeps its title, chapters, bibliography names and author details in its own _quarto.yml files.

The slide folder is also a Quarto project. It contains local dependencies so that you can copy the whole folder and present independently of the course book.

The documentation uses the course theme

This website loads the same _template.yml as the course book, with local copies of assets/custom.css, assets/dark.scss and the accompanying scripts and filters. It therefore uses Source Sans Pro and Roboto Slab, the teal/orange palette, the customised light/dark appearance, table styling and code highlighting described in the book guide. assets/docs.css adds only the guide grid and other documentation layout rules. The local YAML keeps the documentation in English and disables external comments.

Reading the feature descriptions

Each feature identifies its origin:

Label Meaning
Native Quarto, Pandoc or Reveal.js functionality, configured for this template.
Extension Functionality supplied by a named third-party extension.
Local A helper, configuration or modification present in this teaching setup. This label does not claim original authorship of upstream code.

The guides focus on the configured behaviour, including local differences. For example, .bg means a teal highlight in the book and an orange highlight in slides. Questions use the source class .question, not .callout-question; the latter is generated by the custom-callout extension.

Scope of this draft

The reference was checked against the central template on 4 November 2026, using Quarto 1.8.27. Extension versions are recorded in Maintenance. A working slide demonstration is embedded in the slide guide; the book guide contains working callout and exercise examples. Examples referencing assets/example.png, a bibliography key or a dataset require your own corresponding resource.

HTML is the main teaching output. The Python scripts can also produce clean notebooks and slide PDFs, but those outputs do not reproduce every browser interaction. Compatibility notes are included where this distinction affects authoring.
